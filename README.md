# Portfolio Template

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Run it

Open `index.html` in your browser, or start a local server from this directory:

```sh
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Make it yours

- Replace the sample name, introduction, and contact details in `index.html`.
- Update the project cards with your own work and links.
- Adjust the colors and typography in the custom properties at the top of `styles.css`.

The mobile menu is handled by `script.js`; the rest of the page works without JavaScript.
